# nanobanana ロゴ生成プロンプト

哲学レスバのブランディング画像を nanobanana で生成するためのプロンプト集。
`design/assets/` の SVG/PNG は使わず、生成物を `apps/web/public/branding/` に配置する。

## 生成方針

- **B案（装飾のみ）を推奨** — 日本語テキストは AI 画像で崩れやすいため、雰囲気を固めてから Figma 等で文字を載せる
- **A案** — 一発生成に挑戦する場合。末尾に「日本語追記」を必ず足す


## 配置ファイル名

```text
apps/web/public/branding/
  logo-mark.png      # シンボルマーク（ヘッダー VS バッジ）
  wordmark.png       # ワードマーク「哲学レスバ!!」
  hero-resuba.png    # トップヒーロー「哲学者と、レスバ!!」
  select-title.png   # 哲学者選択「対戦相手を選べ!!」
```

`grunge-noise` はロゴではないため nanobanana 不要（CSS ノイズオーバーレイで対応）。

## 背景透過処理

nanobanana がチェッカー柄の「偽透過」を出力した場合、以下で本物の透過 PNG に変換する。

```sh
python3 design/assets/remove-checkerboard-bg.py
```

- 入力: `design/assets/` の `logo-mark.png` / `wordmark.png` / `hero-logo.png` / `select-title.png`
- 出力: `apps/web/public/branding/`（`hero-logo.png` → `hero-resuba.png` にリネーム）

## 出力設定の目安

- 形式: 後で背景を透過できるようにコントラストの高い背景色でグラデーションやシャドウは使わない
- 余白: 要素の周りに 10〜15%
- 解像度: 表示サイズの 2 倍程度で生成

## 日本語を AI に任せる場合の追記（A案のみ）

```
重要：日本語は指定した文字と完全一致させること。誤字・別の漢字・読めない文字は禁止。
シャープなベクター風の字形、筆文字でも輪郭ははっきり。
```

## 1. シンボルマーク（`logo-mark`）

**用途**: ヘッダー左の VS マーク（表示高さ 52px）  
**比率**: 1:1（1024×1024 推奨）

### A. 文字込み

```
哲学レスバというWebアプリのシンボルマーク。
中央でぶつかり合う2つの漫画風吹き出し、
左はコーラル朱 #E85D4C に太い黒枠、右は白に太い黒枠、
吹き出しの間に短いスパーク線、
中央に黄色 #FFE100 のスタンプ風バッジ、太字の黒文字で「VS」、
シアンとオレンジのスピードラインを少し添える、
フラットなベクター・ステッカー風、中央配置、透過背景、
小さく表示しても判別できるクリーンなエッジ
```

### B. 装飾のみ（推奨）

```
上記と同じ構図だが文字は一切なし。
ぶつかり合う2つの吹き出し、スパーク線、
中央に空の黄色スタンプ型バッジ（後から「VS」を載せる）、
フラットベクター、透過背景、1024×1024
```

## 2. ワードマーク（`wordmark`）

**用途**: ヘッダー「哲学レスバ!!」（表示高さ 52px）  
**比率**: 横長 5:2 前後（2048×800 推奨）

### A. 文字込み

```
横長ワードマークロゴ。日本語テキストは必ず正確に「哲学レスバ!!」。
「哲学」は黒いチップ状ラベル、「レスバ」は巨大な筆致バトル文字、
シアン→オレンジ→黒→白の4層アウトラインで発光感、
赤い「!!」をスタンプ風に添える、
極太ゴシック、特撮ファイトポスター調、横並び、透過背景、
小さくても読める、サブタイトルなし、余計な英字なし
```

### B. 装飾のみ（推奨）

```
日本のバトル系アプリ用の横長ワードマーク装飾、文字は入れない。
左に黒ラベル型チップ、中央に筆文字風の爆発スプラッシュ、
右に赤スタンプの「!!」用の丸印だけ、
4文字分の空きスペースを残す、透過背景、2048×800
```

## 3. ヒーローロゴ（`hero-resuba`）

**用途**: トップ画面メイン（最大幅 509px）  
**比率**: 横長 2.6:1（2048×780 推奨）

### A. 文字込み

```
日本のWebアプリ・ランディング用の横長ヒーロータイトル。
上部に小さなプリファイト風バナー、日本語「哲学者と、」
（黒バナー、シアン枠、白文字）、
メインは巨大な「レスバ!!」の筆致バトル文字、
4層アウトライン（シアン・オレンジ・黒・白）、
背後にインク飛沫の楕円、小さく傾いた英字「FIGHT」ゴム印スタンプ、
スピードライン、左右に縦のカラーバー、
闘技場入場ポスター感、背景は透過または薄いクリーム #FAFAF8、
構成は上にバナー、中央下にメイン文字
```

### B. 装飾のみ（推奨）

```
横長ヒーローポスター構図、日本語文字は一切なし。
上部にシアン枠付きの黒横バナー（空）、
中央にメインタイトル用の巨大筆致爆発シェイプ、
インク飛沫、スピードライン、左右に青と紫の縦カラーバー、
英字「FIGHT」の小さな傾きスタンプのみ可、
薄いクリーム背景 #FAFAF8、2048×780、文字を載せる余白を残す
```

## 4. 哲学者選択タイトル（`select-title`）

**用途**: 哲学者選択画面（最大幅 560px、軽く傾ける）  
**比率**: 横長 3:1（2048×680 推奨）

### A. 文字込み

```
横長タイトルグラフィック。日本語は必ず正確に「対戦相手を選べ!!」。
筆致バトル文字、白塗りにシアン・オレンジ・黒の太い縁取り、
全体を約-3度傾けたステッカー感、
オレンジ色のハードドロップシャドウ、
ポップパンクな闘技場・対戦相手選択画面のヘッダー、
攻撃的だけど楽しい、透過背景、人物イラストは入れない
```

### B. 装飾のみ（推奨）

```
横長で約-3度傾いたステッカー型の筆致グラフィック、文字なし。
白い筆致フォルムにシアン・オレンジ・黒の縁取り、
オレンジのハードシャドウ、中央に日本語タイトルを載せる空き、
対戦相手選択画面用ヘッダー装飾、透過背景、2048×680
```
