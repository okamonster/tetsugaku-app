# nanobanana 哲学者肖像生成プロンプト

哲学レスバの哲学者アバター画像を nanobanana で生成するためのプロンプト集。
`design/nanobanana-logo-prompts.md` と同系統のポップパンク・バトル漫画風。

## 生成方針（決定済み）

| 項目 | 内容 |
|------|------|
| 画風 | ポップパンク・バトル漫画風（ロゴと同系統） |
| 再現度 | 強いカリカチュア（歴史的特徴を誇張） |
| 背景 | 正方形・単色フラット（`avatarBg` と完全一致） |
| 構図 | バストアップ・正面〜微斜め（円形クロップ前提） |
| 演出 | 軽いアクセント（スピードライン・スパーク・汗マーク程度） |
| キャラ色 | `color` を服・小物のアクセントに使用 |
| 衣装 | 歴史的衣装をデフォルメ |
| 文字 | 一切なし |
| サイズ | 1024×1024 |

## ワークフロー

```text
1. design/assets/philosophers/ に複数候補を生成（英語仮名で管理可）
   例: socrates-v1.png, socrates-v2.png
2. 画風統一・円形クロップの見え方で選定
3. 採用分をリネームして配置
   apps/web/public/philosophers/ソクラテス.png
   apps/web/public/philosophers/プラトン.png
   apps/web/public/philosophers/カント.png
   apps/web/public/philosophers/ニーチェ.png
```

> **実装メモ**: コードの `PhilosopherId` は英語（`socrates` 等）。画像ファイル名は日本語。
> 実装時にパスマッピングを `philosophers.ts` 等で行う。

## 選定チェックリスト

同じプロンプトでも seed 次第でブレるため、候補比較時に以下を確認する。

- [ ] 4人並べたときに画風が揃っているか
- [ ] 80px 円形クロップで顔の特徴が潰れていないか
- [ ] 36px 想定でもシルエットで誰か判別できるか
- [ ] 背景色が `avatarBg` と近似しているか（後処理で単色置換も可）
- [ ] 文字・透かし・ロゴが紛れ込んでいないか
- [ ] 背景がチェッカー柄の偽透過になっていないか

## 背景色の単色置換（任意）

生成結果の背景色が `avatarBg` とズレた場合、単色フラット前提なので後処理で置換しやすい。

```sh
# 例: ImageMagick で背景を avatarBg に統一（要インストール）
# convert input.png -fuzz 8% -fill "#DBEAFE" -opaque "#近似色" output.png
```

## 出力設定の目安

- 形式: PNG（正方形 1024×1024）
- 背景: 各キャラの `avatarBg` を全面単色で指定
- 余白: 頭の上・肩の左右に 10〜15% のセーフマージン（円形クロップ用）
- 解像度: 1024×1024（カード 80px の約 2 倍）

## 生成のコツ

1. **1人ずつ生成** — 4人同時指定は画風がブレやすい
2. **共通スタイルを毎回末尾にコピペ** — ロゴ生成と同じ運用
3. **2〜4枚ずつ出して比較** — 同じプロンプトで表情の良いものを選ぶ
4. **選定時は円形プレビュー** — Figma やブラウザで `border-radius: 50%` をかけて確認
5. **画風の基準はソクラテス** — 最初にソクラテスで画風を固め、他3人はそれに合わせる
