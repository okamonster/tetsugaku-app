# tetsugaku-app（哲学アプリ）

哲学者とレスバして遊べる Web アプリ。

> **要件定義**: ✅ 完了（2025-06-07）
> **デザインコンセプト**: ✅ 完了（2025-06-07）
> **実装**: ⏸️ Pencil でデザイン完成まで着手しない

## コンセプト

ユーザーが哲学者のペルソナと対話し、論争（レスバ）を楽しむエンターテインメント向け Web アプリ。

**アプリ名**: 哲学レスバ

**デザインキーワード**: ポップパンクな哲学闘技場 — 真面目な哲学アプリではなく、選んで・投げて・論じる遊びの空間。

**ロゴ**: 衝突する2吹き出し＋中央 VS バッジのシンボルマーク ＋「哲学レスバ」ワードマーク

**バトルビジュアル**（参考: 特撮「FIGHT!!」ポスター）: 多層グロー文字・インクスプラッシュ・ダークバトルパネル・特撮カラーバー・グランジノイズ。ヒーロー表記は「レスバ!!」

**デザインアセット（SVG）**: `design/assets/` — `hero-resuba.svg`, `wordmark.svg`, `select-title.svg`, `grunge-noise.svg`

## 技術方針

- **フレームワーク**: TanStack Start
- **デプロイ**: Cloudflare Pages
- **LLM**: Chrome 内蔵のローカル Gemini（Gemini Nano / Chrome Built-in AI）
- **パッケージ管理**: pnpm
- **モノレポ**: Turborepo を維持（将来バックエンド追加などに備える）
- **移行方針**: `create-turbo` 生成物（`apps/` 配下の Next.js アプリ等）を削除し、TanStack Start でクリーンスタート

> **Note**: 現状は Turborepo + Next.js スターター。実装時に `apps/` を整理し TanStack Start アプリを新設する。

## 開発

```sh
pnpm install
pnpm dev
```

## レスバの進行フロー

1. 哲学者を選ぶ
2. お題を決める（自由入力 or 選択式 UI）+ **制限時間を選ぶ（5分 / 8分 / 10分）**
3. 時間制バトルで論争
   - 哲学者が敗北宣言 → ユーザー勝利
   - ユーザーが降参 → 哲学者勝利
   - 時間切れ → 即時審判が勝敗を判定（引き分けなし）
4. リザルト画面で結果を表示

## デザインコンセプト

### 体験トーン

- **闘技場 × 挑発的パンク** を掛け合わせ、初見で「おもしろそう」と感じるエンタメ感
- 入り口は派手、お題入力・チャットは整然で読みやすく

### カラーパレット

| 用途 | 色 |
|------|-----|
| 背景 | `#FAFAF8` |
| テキスト | `#1A1A1A` |
| グローバルアクセント | `#E85D4C` |
| ソクラテス | `#2563EB` |
| プラトン | `#7C3AED` |
| カント | `#475569` |
| ニーチェ | `#DC2626` |

### 画面ごとの演出

| 画面 | 方針 |
|------|------|
| トップ | 斜めストライプ、極太タイトル、スタンプ、レスバ開始 CTA |
| 哲学者選択 | 傾きカード、キャラ色ボーダー、ポップ肖像 |
| お題入力 | 整然、シール風カテゴリチップ |
| チャット | アバター付き吹き出し、哲学者色左ボーダー |

| LLM 未準備 | カントが理性的に案内 |

### 哲学者ビジュアル

- ポップイラスト（太線・フラット）で統一 + キャラごとの小ネタ
- AI 生成肖像 → `apps/web/public/philosophers/`

## 哲学者（MVP）

固定 4 人で開始。将来カテゴリ追加・拡張予定。

| 哲学者 | レスバでの特徴（想定） |
|--------|------------------------|
| ソクラテス | 問答法で論点を剥がす。相手を問い詰める |
| プラトン | イデア論・正義を軸に理想主義的に論じる |
| カント | 冷静・論理的。義務論・理性を重視 |
| ニーチェ | 挑発的・攻撃的。既存の価値観を否定する |

## お題の方針

- **お題の内容**: 抽象論より **私生活・身近な生活感のある話題** を中心にする
- 選択式 UI は **5 カテゴリ** で分類（具体リストは後日決定）

### お題カテゴリ（MVP）

| カテゴリ | 方向性 |
|----------|--------|
| 人間関係 | 恋人・友人・家族 |
| 仕事・キャリア | 働き方・モチベーション |
| SNS・現代生活 | デジタル社会の違和感 |
| 自分自身 | 自己肯定・不安・成長 |
| 恋愛・性 | より個人的なテーマ |

## データ永続化

- **MVP**: 会話・履歴は保存しない（リロードで消える）
- **将来**: `apps/backend` + インフラで履歴保存・一覧・再開を実装

## 画面構成（MVP）

1. **トップ** — キャッチコピー + 使い方（3 ステップ）+ 「レスバ開始！」ボタン + 注記（Chrome 専用・保存なし）
2. **哲学者選択** — 4 人から選ぶ
3. **お題入力** — 自由入力 + 選択式 UI + 制限時間選択（5分 / 8分 / 10分）
4. **チャット画面** — タイマー + 降参ボタン + 論争
5. **リザルト画面** — 勝敗表示 + 審判コメント + もう一回 / トップへ

## ブラウザ対応

- **Chrome 専用**（ローカル Gemini 利用のため）
- 非対応ブラウザでは案内画面を表示（Chrome 推奨バージョン・モデル設定手順を案内）
- フォールバック API は MVP では実装しない

## UI・スタイリング

- **Tailwind CSS + shadcn/ui**
- チャット UI・履歴カード・フォーム類は shadcn/ui コンポーネントを活用
- **テーマ**: MVP はライトモードのみ。将来ダーク / ライト切替に対応できる設計にする

## モノレポ構成

```
apps/
  web/          # TanStack Start（フロントエンド）
  backend/      # バックエンド（将来）
packages/
  common/       # 共有ロジック・型定義
  ui/           # 共有 UI コンポーネント
  tsconfig/     # 共有 TypeScript 設定
```

## MVP スコープ

- `apps/web` + `packages/{common,ui,tsconfig}` のみ実装
- `apps/backend` は MVP では作らない（将来追加）

## 言語

- **日本語のみ**（UI・哲学者の返答・お題すべて）
- 哲学者は現代日本語で論じる（思想・論調は各ペルソナを維持）

## LLM 応答表示

- 内部ではストリーミング生成
- UI では生成中はローディングアニメーションを表示
- 全文生成完了後にまとめて表示（トークン逐次表示はしない）

## リロード・離脱時の UX

- チャット画面に「会話は保存されません」の注意表示
- ページ離脱時（タブ閉じ・戻る等）に確認ダイアログ
- リロードすると会話は消える

## Chrome ローカル LLM 未準備時

- **起動時に API 可用性をチェック**
- 利用不可の場合は案内画面を表示（チャット機能は使えない）
- 案内内容: 対応 Chrome バージョン、AI 機能有効化手順、モデルダウンロードの案内

## 哲学者選択 UI

- **イラスト / 肖像** で各哲学者を表現
- カードに名前・キャッチコピー・論じ方の説明を併記
